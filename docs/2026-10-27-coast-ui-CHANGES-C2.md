## 0. 한 줄 요약

한 화면에 다 넣던 것을 **메뉴 5개**(상황판 · 지도 · 선박 목록 · 수신 현황 · 신호 품질)로 나눴다. 지도는 MarineTraffic 식(툴바 아이콘 4개가 접혀 있고

## 6. 못 한 것 · 알아 둘 것

- **⑤ 원인 카드의 "미상" 몫은 구조적으로 0 %** 에 가깝다 — 1차 식(T − (e+x+c))이 셋을 더하면 T 가 되게 짜여 있어, 환경값이 없는 배에서도 0 이 나온다. 식은 1차 `signal.ship_cards` 그대로이고 바꾸지 않았다(판정·근거 변경 범위 밖). 해안국 전체 카드는 그 식을 배마다 벡터로 돌려 Σ|부분| 비율로 합친 것(`signal_summary`), 으뜸 원인·⚑ 수는 배 단위.
- **상태(항해 중/정박) 필터**는 시점 스냅샷의 SOG 로 판단한다 — 목록도 같은 필터를 쓰므로 시점을 옮기면 목록의 항해 중/정박 집합이 바뀐다(SOG 없는 배는 둘 다 아님).
- 'last' 출처는 **시점 이전** 행만 거슬러 본다(시점 뒤 행은 아직 모르는 정보로 침). 항적 추정은 1차 설계값(30 m · 20행) 그대로.
- 실해역 `course` 에 360 보다 큰 값(최대 409.5)이 45행 있다 — 전부 "없음"으로 처리(≥ 360). DB 원값 문제는 ml_all 쪽 일.
- 작은 지도(①)는 상호작용 없음(OL interactions []) — 확대·이동은 ② 에서.
- 해시 질의에 필터가 실리므로 주소를 복사하면 같은 화면·같은 필터가 열린다. 단 선택 배(`mmsi`)는 지도 화면에서만 실린다.
- `d3.min.js`·`d3-sankey.min.js` 삭제(VERSIONS.txt 에 적음). 그래프는 전부 DOM/CSS.
