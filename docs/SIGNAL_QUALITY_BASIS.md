# 신호 품질 — 등고선 값의 근거와 식 (coast_ui §4)

2026-10-27. 화면의 "신호 품질" 층·카드가 **왜 그 숫자**를 쓰는지, 어디서 왔는지 적는다. 코드는 `coast/signal.py` 하나이고
여기 표의 상수와 1:1 이다. 근거가 없는 값은 §4 표에 **설계값**으로 따로 적었다(실해역 분포로 정한 값은 없다).

## 1. 두 등고선 층

### (가) 수신 여유 (dB) — "표준 감도에 얼마나 여유가 있나"

    수신 여유 = RSSI(dBm) − (−107 dBm)

| 등고선 | 뜻 | 근거 |
|---|---|---|
| **0 dB** | 표준이 요구하는 최소 수신기 감도 **−107 dBm**(PER 20 %) — 이 아래는 수신 자체가 불안 | ITU-R M.1371-6 (02/2026) 수신기 감도, Table (Minimum receiver requirements) — M.1371-4/-5 표 7 과 같은 값 |
| **10 dB** | 동일 채널 보호비 **10 dB** — C/(I+N) ≈ 10 dB 에서 PER 20 %. 0~10 은 간섭 하나면 끊길 여유, ≥ 10 은 보호비만큼 여유 | 같은 권고 Co-channel rejection (10 dB) |
| **20 dB** | 보호비의 두 배 — "넉넉" (표준 값 아님, 10 dB 간격의 자연스러운 다음 눈금) | 설계값 (§4) |

종합 3단계(배·해안국 카드): **나쁨 < 0 · 보통 0~10 · 좋음 ≥ 10** — 같은 두 숫자로만 가른다. 배 값은 기간 안 RSSI **중앙값**.

참고: 시판 장비의 전형 감도는 −109 dBm 안팎(Report ITU-R M.2169)이라 실제로는 0 dB 아래에서도 얼마간 들린다 — 그래서 0 은
"끊김" 이 아니라 "표준이 보장하지 않는 영역" 으로 읽는다.

### (나) 환경 잔차 (dB) — "이 자리가 원래 얼마나 낮게(높게) 들리는가"

    환경 잔차 = rssi_resid = 관측 RSSI − 거리 기대값(ml_all 거리 모델 그대로, 열 `rssi_resid`)

거리 기대값은 ml_all `scripts/datagen/build_risk_map.py` 가 만든 거리 모델(ml_all 의 `rssi_model`)이고 여기서는 **다시 계산하지
않는다**(판정과 같은 값을 쓰기 위해). 점-대-면 전파 예측의 표준 참조는 ITU-R P.1546(해상 경로 곡선)이지만, 이 화면은 P.1546 곡선을
직접 쓰지 않고 ml_all 거리 모델의 잔차를 그대로 보간한다(판정과 한 잣대).

| 등고선 | 뜻 |
|---|---|
| **−10 / −5 / 0 / +5 dB** | 거리 기대값 대비. 음수가 큰 곳 = 가림·음영 의심, 0 = 기대대로, + = 잘 들리는 곳 |

"가림 의심" 문턱 **−X = −4 dB** 는 ml_all `engines/threat/rules.py` `THRESHOLDS["rssi_resid_db"]`(4.0) 와 같은 값 — 배 카드의
해역 환경 몫에 ⚑ 표시를 다는 기준이다. 설계값(§4).

## 2. 등고선을 만드는 법 (두 층 같음)

1. 기간 안 **위치 있는 보고**(has_pos) 의 점값(수신 여유 또는 환경 잔차).
2. **0.5 km 격자 칸**마다 (칸, 배) 중앙값 → 칸 중앙값. 말 많은 배 한 척이 칸 값을 정하지 않게(ml_all 위험 해역 지도와 같은 원칙).
   배 **3 척 이상**인 칸만 표본점(`MIN_SHIPS_PER_CELL`).
3. **정규 크리깅(Ordinary Kriging)** 으로 격자 보간.
   - 경험 반분산 γ(h) 를 무작위 쌍 ≤ 200,000 개·15 km 까지 15 구간으로 재고, **지수 모델** γ(h) = c₀ + c₁(1 − e^(−h/a)) 를 최소제곱으로 맞춘다
     (너깃 c₀, 부분 문턱 c₁, 범위 a). 맞추기에 실패하면 분산 기반 기본값(c₀ = 0.2·Var, c₁ = 0.8·Var, a = 5 km).
   - 격자점마다 가장 가까운 **16 표본점**으로 OK 연립방정식(공분산 = 문턱 − γ, 가중치 합 = 1 의 라그랑주 조건)을 푼다(국소 크리깅, 배치 solve).
   - 표본점이 **30 개 미만**이면 배 1척 이상 칸을 **IDW(역거리 제곱, 이웃 16)** 로 대체하고 범례에 "IDW 대체" 를 적는다.
4. **육지 마스크**: ml_all `config/sea_mask.json`(0.005° 항행수역 격자, 이웃 1칸까지 바다) 밖은 비운다.
   **반경 밖**: 가장 가까운 표본점이 **3 km** 보다 멀면 그리지 않는다.
5. **marching squares**(선형 보간, 안장은 칸 중앙값으로 가름) 로 등고선. 선분에 방향(값 ≥ 레벨이 왼쪽)을 두고 끝점 → 시작점으로
   이어 붙인다 — d3-contour 와 같은 알고리즘을 서버(Python)에서 계산해 GeoJSON LineString 으로 내려준다.

왜 크리깅인가 — 라디오 환경 지도(REM) 보간 연구들이 측정점이 성긴 전파 세기 장에 정규 크리깅이 IDW·스플라인보다 오차가 작음을 보인다
(아래 출처). 반분산 모델을 데이터에서 맞추므로 "얼마나 멀리까지 비슷한가"(범위 a)가 데이터로 정해진다.

### 생존 편향 (범례에 그대로 적음)

수신된 메시지만 보이므로 **아주 나쁜 곳은 값이 낮게 나오는 것이 아니라 점이 없다.** 그래서 두 층을 같이 켤 수 있게 했다.

- **보고 밀도(배×분)** — 0.5 km 칸마다 (배, 분) 조합 수. 점이 없는 칸 = "좋은 곳" 이 아니라 "들리지 않은 곳" 일 수 있다.
- **ENV_LOSS 비율** — 칸의 행 중 REPORT_RATE_SLOW 환경성 유실(slow_kind = ENV_LOSS) 갈래 비율.

## 3. 배 원인 카드 — 네 몫 (dB 귀속)

배 상세의 "신호 품질 — 원인별" 은 그 배의 저하를 네 몫으로 나눠 막대로 보인다. 전부 기간 안 그 배 행의 평균이다.

    전체 저하  T = min(0, mean snr_resid)                 거리 기대 대비 SNR 부족분
    해역 환경  e = min(0, 환경 잔차 등고선 값)              항적 위 (나) 장 값의 중앙값 — 다른 배들로 만든 장
    송신기    x = min(0, mean rssi_resid − e)             같은 자리 다른 배보다 더 약한 정도(배 고유)
    혼잡·간섭  c = min(0, mean snr_resid − mean rssi_resid) 세기로 설명되지 않는 SNR 추가 손실 = 잡음·간섭 상승
    미상      u = min(0, T − (e + x + c))                  셋으로 설명되지 않는 나머지(환경값 없음 등)
    몫 %     = |부분| ÷ (|e| + |x| + |c| + |u|)             전체 저하가 0 이면(기대보다 잘 들림) 몫은 모두 0

카드 문구와 ⚑ 기준.

| 몫 | 문구 | ⚑ 기준 |
|---|---|---|
| 송신기 약함 | "다른 배보다 n dB 약하게 들림" — n = 그 배 잔차 평균 − 다른 배들의 잔차 평균 중앙값 | 룰 `rule_slow_kind = TX_WEAK` 가 있거나, n ≤ −2.5 SE 이고 행 ≥ 25 (ml_all `THRESHOLDS["txweak_se"]` = 2.5 와 같은 기준) |
| 해역 환경(가림) | "이 위치는 원래 n dB 낮게 들리는 곳" — n = (나) 장의 항적 위 값 | n ≤ −4 dB (ml_all `rssi_resid_db`) |
| 혼잡·간섭 | "주변 배 n척(3 km), 슬롯 n% 사용" — 같은 분 반경 3 km 안 다른 배 수(ml_all `NEAR_KM` 과 같음) + 그 프레임의 보고 수 ÷ 2250 | 슬롯 사용률 ≥ 50 % (설계값) |
| 미상 | 나머지 | — |

ml_all 콘솔의 원인 나누기(`explained_shares`, 분산 분해)와 **정의가 다르다** — 그쪽은 해역 전체 분산을 위치·혼잡·나머지로 나누고,
여기는 배 한 척의 dB 를 넷으로 귀속한다. 목적이 다르니(해역 진단 vs 이 배를 왜 못 듣나) 숫자도 다르다.

## 4. 설계값 표 — 근거 없음, 바꿀 수 있음

| 값 | 어디 | 쓰임 | 비고 |
|---|---|---|---|
| 20 dB | 수신 여유 셋째 등고선 | "넉넉" | 보호비 10 dB 의 두 배 |
| −4 dB | 가림 의심 문턱 | 카드 ⚑ | ml_all `rssi_resid_db` 와 같은 값(그쪽도 설계값, 생성 데이터 ds_007 창 비교로 유지) |
| 0.5 km | 격자 칸 | 표본점·보간·밀도 | ml_all 위험 해역 지도의 최소 격자와 같음 |
| 3 척 | 칸을 표본점으로 치는 최소 배 수 | 크리깅 표본 | ml_all `MIN_SHIPS` 와 같음 |
| 30 개 | 크리깅 최소 표본점 수 | 미만이면 IDW | — |
| 16 | 국소 크리깅·IDW 이웃 수 | — | — |
| 15 km | 반분산을 재는 최대 거리 | — | — |
| 3 km | 반경 밖 비움 · 혼잡 반경 | — | ml_all `NEAR_KM` 과 같음 |
| 10 분 | 시점에서 이보다 오래된 마지막 보고 = 반투명 | 지도 | 요구 §2-6 |
